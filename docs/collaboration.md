# 协作与工作流

## 双电脑开发
- 当前项目在公司和家里两台电脑之间切换开发
- 换设备前后，优先同步最新代码并查看 [release-notes.md](release-notes.md) 了解正式版本变化
- 重要功能规划可写入专门方案文档，例如 [optimization-plan.md](optimization-plan.md)

## 多 AI / CLI 工具协作
- 不要假设任何工具会自动理解仓库背景
- 开始工作前，应先阅读根目录 [README.md](../README.md) 与 [AGENTS.md](../AGENTS.md)
- 涉及部署、版本、优化方案时，再分别阅读对应 `docs/` 文档

## 协作习惯
- 正式版本发布时，必须同步更新 [release-notes.md](release-notes.md)
- 版本升级规则统一遵循 [versioning.md](versioning.md)
- 部署必须遵守 [deployment.md](deployment.md) 的平滑更新规则

# v1.2.0 大更新说明

**日期**: 2026.5.5
**版本号**: v1.2.0
**性质**: 大更新（Major Update）

---

## 概述

本次 v1.2.0 是一次大规模的外观系统升级，参考了 komari 项目的配置体系与模板注入方案，为枪械网页引入了高度可自定义的视觉外观系统。用户现在可以通过全新的「外观设置」页面，深度定制站点的视觉风格，包括站点信息、自定义代码注入、Favicon、背景图片、毛玻璃效果等。

---

## 核心功能

### 1. 全新外观设置页面

在左侧导航栏「系统设置」上方新增「外观设置」独立入口，使用 `Palette` 图标标识。页面包含以下模块：

- **站点信息**：修改站点名称与站点描述，描述用于元信息及社交媒体卡片
- **自定义代码**：支持在 `<head>` 和 `</body>` 前注入任意 HTML/CSS/JavaScript
- **自定义 Favicon**：上传本地图片作为浏览器标签页图标
- **自定义外观总开关**：一键启用/关闭全局背景图与玻璃拟态效果
- **实时预览**：内置预览卡片，调整参数即时看到玻璃拟态效果

### 2. 玻璃拟态效果系统

开启自定义外观后，支持以下参数调节：

| 参数 | 范围 | 说明 |
|------|------|------|
| 背景图片 URL | 任意 URL | 支持图片直链或随机图 API，留空则不显示 |
| 本地上传 | - | 上传后自动保存到服务端并回填 URL |
| 背景固定显示 | Toggle | 开启后背景固定不随页面滚动 |
| 毛玻璃模糊强度 | 0-20px | 数值越大越模糊 |
| 整体透明度 | 70-100% | 控制玻璃层覆盖透明度 |
| 圆角大小 | 0-16px | 全局控制卡片与面板圆角 |
| 光晕强度 | 0-20px | 控制组件阴影/光晕强度 |

### 3. 服务端模板注入

Production 模式下，Express 接管 `index.html` 渲染，动态注入以下内容：

- `<title>` → 站点名称
- `<link rel="icon">` → 自定义 Favicon URL
- `</head>` 前 → 自定义 Head 代码
- `</body>` 前 → 自定义 Body 代码

开发模式（Vite dev）下通过前端 DOM 操作模拟注入。

### 4. 配置持久化

- 所有外观配置写入 `runtime/appearance.json`
- 上传文件（Favicon、背景图）保存到 `runtime/uploads/`
- 运行时数据与源码分离，避免部署覆盖

## 升级注意事项

1. **Docker 部署**：确保 `runtime/` 目录已挂载到宿主机卷，否则上传文件和配置会在容器重建后丢失
2. **缓存清理**：Favicon 更新后浏览器可能需要强制刷新（Ctrl+F5）才能看到新图标
3. **背景图片性能**：大尺寸背景图在低配设备上可能影响滚动性能，建议开启「背景固定」并使用经过压缩的图片

## 后续修复与优化（v1.2.0 补充）

### 1. 上传路径修复
- 前端上传请求 URL 从 `/api/upload/:type` 修正为 `/api/appearance/upload/:type`，与后端路由对齐，解决 404 错误

### 2. 保存按钮与草稿模式
- 外观设置页面改为**草稿模式**：所有输入、滑块、开关的改动先保存在组件本地 `draft` state
- 新增**保存设置**按钮，点击后才将完整配置 `POST` 到 `/api/appearance`，成功后更新全局状态并提示"外观设置已保存，全站生效"
- 新增**恢复默认**按钮，一键重置为默认配置并同步后端
- 保存/恢复操作均有明确的成功/失败状态提示（3 秒自动消失）

### 3. 滑块拖动流畅优化
- `SliderField` 组件内部增加本地 `localValue` state
- 拖动滑块时仅更新本地值，不触发父组件重渲染，彻底消除卡顿感
- 滑块数值实时显示在标签旁

### 4. 全站玻璃拟态真正生效
- **修复背景图被遮挡**：主容器（`flex min-h-screen`）在启用自定义外观时背景设为 `bg-transparent`，不再用不透明底色盖住背景图
- **新增全局遮罩层**：`fixed inset-0 z-[1]` 的遮罩应用 `backdrop-filter: blur()` + 半透明背景（白/黑根据 Dark Mode 切换），位于背景图之上、内容之下
- **全站卡片自动玻璃化**：通过 `<style>` 标签动态注入 CSS，自动覆盖 `.bg-white`、`.bg-zinc-50`、`.dark:bg-[#121214]` 等主要面板背景类为半透明 + `backdrop-filter: blur()`
- 按钮/输入框保持更高不透明度（95%），确保文字可读性
- 边框颜色自动调整为玻璃风格的白边/暗边
- **效果**：保存后全站所有页面（首页、社区、设置等）的卡片和面板均透出背后的模糊背景图，实现真正的全屏玻璃拟态

## 后续修复与优化（v1.2.0 第三次补充）

### 1. CSS 选择器转义真正修复
- 之前动态注入的 `<style>` 中所有带 `:`、`[`、`]` 的 Tailwind 类名选择器（如 `.bg-[#F8F9FA]`、`.dark:bg-[#121214]`）转义不正确，导致浏览器直接忽略这些规则
- 全部改为 JavaScript 模板字符串中的正确双重转义（`\\:` `\\[` `\\]`），CSS 解析后得到 `.bg-\[#F8F9FA\]`、`.dark\:bg-\[#121214\]` 等合法选择器
- **Sidebar 导航栏**、**今日密码面板**、**系统设置卡片**、**社区帖子与评论区**、**首页枪械卡片**全部真正被玻璃化覆盖，不再仅外观设置页面生效

### 4. 每页卡片数自定义

## 后续修复与优化（v1.2.0 第四次补充）

### 1. 删除无用设置
- 移除 `AppearanceConfig` 中的 `gunCardOpacity`、`gunCardColorLight`、`gunCardColorDark` 字段及对应 UI 面板
- 枪械卡片背景统一由全局玻璃化 CSS 控制，不再需要独立配置

### 2. 外观设置页面卡片统一透明
- `AppearanceSettingsPage` 的 `panelClass` 增加 `bg-white dark:bg-[#121214]` 类名
- 全局 CSS 注入已覆盖 `.bg-white` / `.dark:bg-[#121214]`，外观设置页面自身面板终于也被玻璃化，与其他页面完全一致

### 3. 版本号更新
- `package.json` version 从 `1.1.8` 更新为 `1.2.0`
- 左下角 `Sidebar` 版本标签和 `App.tsx` mobile 版本标签自动同步

### 4. 首页卡顿性能优化（关键）
- **提取 `StyleInjector` 组件**：将 `<style>` CSS 注入从 `App` 内部提取为独立 `React.memo` 组件 `StyleInjector`，只在主题/外观配置变化时重新计算 CSS 字符串，避免 App 每次重渲染都重新解析大量 `!important` 规则
- **简化 `motion.div` 动画**：首页卡片 `motion.div` 移除 `delay: idx * 0.04` 的 stagger 动画，改为所有卡片统一 `duration: 0.3`、`y: 8` 的轻量动画，大幅降低 framer-motion 计算量
- **移除面板级 `backdrop-filter`**：全局 CSS 注入不再给每个 `.bg-white` 元素添加 `backdrop-filter: blur()`，仅保留半透明背景色替换。背景模糊由全屏背景 overlay div 统一提供，避免数十个卡片同时触发 GPU 重绘导致的严重卡顿

### 5. 实时预览增强
- 外观设置「实时预览」区域高度从 `h-48` 增加到 `h-56`
- 在原有通用面板预览旁边新增**枪械卡片模拟预览小窗口**，包含：
  - 体系名称 `M4A1 突击步枪`（应用 `--gun-text-color`）
  - 改枪码示例文本（应用 `--gun-code-color`）
  - 来源作者/日期/链接（应用 `--gun-source-color`）
- 调整透明度/模糊/圆角时，预览窗口同步响应

### 6. 枪械卡片文字颜色自定义
- `AppearanceConfig` 新增 6 个字段：
  - `gunTextColorLight` / `gunTextColorDark` —— 体系名称/型号颜色
  - `gunCodeColorLight` / `gunCodeColorDark` —— 改枪码颜色
  - `gunSourceColorLight` / `gunSourceColorDark` —— 来源作者、链接颜色
- 外观设置新增「枪械卡片文字颜色」面板，6 组颜色选择器（颜色盘 + HEX 输入），留空使用默认颜色
- `App.tsx` `StyleInjector` 注入对应 CSS 变量（`:root` 亮色 / `.dark` 暗色）
- `GunCard.tsx` 体系名称 `h3` / `input` 使用 `var(--gun-text-color, var(--user-gun-color, currentColor))` 实现优先级覆盖
- `VariantItem.tsx` 改枪码 `<code>` 使用 `style={{ color: 'var(--gun-code-color)' }}`
- `VariantItem.tsx` 来源区域使用 `style={{ color: 'var(--gun-source-color)' }}`

### 7. 全屏遮罩层 `backdrop-filter` → `filter: blur()`（卡顿根因修复）
- `App.tsx` 全屏背景 overlay div 原先使用 `backdropFilter: blur(...)`，这会导致浏览器对下方**所有 DOM 进行实时合成重绘**，任何滚动/动画都触发全 viewport 重算 → 严重掉帧
- 改为：**背景图层自身**使用 `filter: blur(...)`（配合 `overflow: hidden + transform: scale(1.05)` 避免边缘白边），遮罩层只保留纯色半透明背景
- `filter: blur()` 只模糊单个元素，不影响页面其他内容的渲染，120 帧恢复丝滑

### 8. 彻底移除 `[class*="..."]` 属性选择器（CSS 性能黑洞）
- 全局 CSS 注入中原有 `[class*="shadow-"]`, `[class*="hover:bg-zinc-100"]`, `[class*="border-zinc-200"]` 等属性选择器
- 浏览器匹配这类选择器时，每次样式计算需要**遍历整个 DOM**扫描 `class` 属性，节点越多开销越大
- 全部替换为明确类名选择器（`.shadow-sm, .shadow-md...` 等）

### 9. `useTheme` 引用稳定化
- `src/hooks/useTheme.ts` 返回值用 `useMemo` 包装，update/reset 函数用 `useCallback` 固化
- 之前 `App.tsx` 任何微小重渲染都会导致 `theme` 对象引用变化，触发整棵树连锁重渲染
- 现在引用稳定，只有配置真正改变时才触发子组件更新

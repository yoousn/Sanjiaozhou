# v1.2.0 大更新说明

**日期**: 2026.5.5
**版本号**: v1.2.0
**性质**: 大更新（Major Update）

---

## 概述

本次 v1.2.0 是一次大规模的外观系统升级，参考了 komari 项目的配置体系与模板注入方案，为枪械网页引入了高度可自定义的视觉外观系统。用户现在可以通过全新的「外观设置」页面，深度定制站点的视觉风格，包括站点信息、自定义代码注入、Favicon、背景图片、毛玻璃效果等。

---

## 核心功能

### 1. 全新外观设置页面

在左侧导航栏「系统设置」上方新增「外观设置」独立入口，使用 `Palette` 图标标识。页面包含以下模块：

- **站点信息**：修改站点名称与站点描述，描述用于元信息及社交媒体卡片
- **自定义代码**：支持在 `<head>` 和 `</body>` 前注入任意 HTML/CSS/JavaScript
- **自定义 Favicon**：上传本地图片作为浏览器标签页图标
- **自定义外观总开关**：一键启用/关闭全局背景图与玻璃拟态效果
- **实时预览**：内置预览卡片，调整参数即时看到玻璃拟态效果

### 2. 玻璃拟态效果系统

开启自定义外观后，支持以下参数调节：

| 参数 | 范围 | 说明 |
|------|------|------|
| 背景图片 URL | 任意 URL | 支持图片直链或随机图 API，留空则不显示 |
| 本地上传 | - | 上传后自动保存到服务端并回填 URL |
| 背景固定显示 | Toggle | 开启后背景固定不随页面滚动 |
| 毛玻璃模糊强度 | 0-20px | 数值越大越模糊 |
| 整体透明度 | 70-100% | 控制玻璃层覆盖透明度 |
| 圆角大小 | 0-16px | 全局控制卡片与面板圆角 |
| 光晕强度 | 0-20px | 控制组件阴影/光晕强度 |

### 3. 服务端模板注入

Production 模式下，Express 接管 `index.html` 渲染，动态注入以下内容：

- `<title>` → 站点名称
- `<link rel="icon">` → 自定义 Favicon URL
- `</head>` 前 → 自定义 Head 代码
- `</body>` 前 → 自定义 Body 代码

开发模式（Vite dev）下通过前端 DOM 操作模拟注入。

### 4. 配置持久化

- 所有外观配置写入 `runtime/appearance.json`
- 上传文件（Favicon、背景图）保存到 `runtime/uploads/`
- 运行时数据与源码分离，避免部署覆盖

## 升级注意事项

1. **Docker 部署**：确保 `runtime/` 目录已挂载到宿主机卷，否则上传文件和配置会在容器重建后丢失
2. **缓存清理**：Favicon 更新后浏览器可能需要强制刷新（Ctrl+F5）才能看到新图标
3. **背景图片性能**：大尺寸背景图在低配设备上可能影响滚动性能，建议开启「背景固定」并使用经过压缩的图片

## 后续修复与优化（v1.2.0 补充）

### 1. 上传路径修复
- 前端上传请求 URL 从 `/api/upload/:type` 修正为 `/api/appearance/upload/:type`，与后端路由对齐，解决 404 错误

### 2. 保存按钮与草稿模式
- 外观设置页面改为**草稿模式**：所有输入、滑块、开关的改动先保存在组件本地 `draft` state
- 新增**保存设置**按钮，点击后才将完整配置 `POST` 到 `/api/appearance`，成功后更新全局状态并提示"外观设置已保存，全站生效"
- 新增**恢复默认**按钮，一键重置为默认配置并同步后端
- 保存/恢复操作均有明确的成功/失败状态提示（3 秒自动消失）

### 3. 滑块拖动流畅优化
- `SliderField` 组件内部增加本地 `localValue` state
- 拖动滑块时仅更新本地值，不触发父组件重渲染，彻底消除卡顿感
- 滑块数值实时显示在标签旁

### 4. 全站玻璃拟态真正生效
- **修复背景图被遮挡**：主容器（`flex min-h-screen`）在启用自定义外观时背景设为 `bg-transparent`，不再用不透明底色盖住背景图
- **新增全局遮罩层**：`fixed inset-0 z-[1]` 的遮罩应用 `backdrop-filter: blur()` + 半透明背景（白/黑根据 Dark Mode 切换），位于背景图之上、内容之下
- **全站卡片自动玻璃化**：通过 `<style>` 标签动态注入 CSS，自动覆盖 `.bg-white`、`.bg-zinc-50`、`.dark:bg-[#121214]` 等主要面板背景类为半透明 + `backdrop-filter: blur()`
- 按钮/输入框保持更高不透明度（95%），确保文字可读性
- 边框颜色自动调整为玻璃风格的白边/暗边
- **效果**：保存后全站所有页面（首页、社区、设置等）的卡片和面板均透出背后的模糊背景图，实现真正的全屏玻璃拟态

## 后续修复与优化（v1.2.0 第二次补充）

### 1. 后端文件上传真正修复
- 安装 `multer` 及 `@types/multer`
- `server/routes/appearance.ts` 上传路由从直接读取 `req` stream 改为 `multer().single("file")` 中间件，正确解析 `multipart/form-data`
- 新增 `/api/appearance/upload/background` DELETE 接口，支持删除已上传的背景图文件

### 2. 滑块彻底不卡顿
- `SliderField` 改用 `useRef` 获取原生 `<input>`，绑定 `defaultValue`
- 拖动时仅通过原生 `onInput` 更新本地 `displayValue`，完全不调用父组件 `setState`
- 鼠标释放（`onPointerUp` / `onMouseUp`）或键盘松开（`onKeyUp`）时才将最终值提交给 `draft`
- 彻底消除拖动过程中的 React 重渲染与页面卡顿

### 3. 整体透明度范围扩展
- 整体透明度滑块范围从 `70~100%` 改为 `0~100%`，支持完全透明到完全不透明

### 4. 全站覆盖范围扩大
- CSS 注入条件从 `customEnabled && backgroundUrl` 放宽为 `customEnabled`，无背景图时玻璃效果也生效
- 新增覆盖 `.bg-zinc-100`、`.bg-[#0b0b0c]`（Sidebar）、`.dark:bg-zinc-800`、`.hover:bg-zinc-100`、`.dark:hover:bg-white/5` 等数十个选择器
- **Sidebar 导航栏**、**系统设置卡片**、**社区帖子卡片**、**评论区**、**动态栏**全部纳入玻璃化范围
- 按钮/输入框/悬停状态均保持更高可读性（95% 不透明度）

### 5. 背景图删除按钮
- 外观设置「背景图片」输入框旁新增删除图标按钮，点击调用 `DELETE /api/appearance/upload/background` 清除已上传文件并清空 URL

### 6. 枪械卡片独立样式设置
- `AppearanceConfig` 扩展 `gunCardOpacity`、`gunCardColorLight`、`gunCardColorDark` 字段
- 外观设置新增「枪械卡片样式」面板，包含：
  - 卡片不透明度滑块（0~100%）
  - 亮色/暗色模式卡片底色颜色选择器（原生 `<input type="color">` + HEX 文本输入）
- `App.tsx` CSS 注入新增 `--gun-card-opacity`、`--gun-card-color-light`、`--gun-card-color-dark` CSS 变量，供全局卡片样式使用
